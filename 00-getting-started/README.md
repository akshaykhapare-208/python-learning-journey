# 00 - Getting Started with Python 🐍

## 📌 About This Folder

This folder contains my first steps in learning Python programming using GeeksforGeeks tutorials.

I will learn what Python is, how to run a Python program, how to write my first program, and how to use comments in Python code.

## 🎯 Learning Objectives

- Understand the basics of Python.
- Learn how to run Python programs.
- Write my first Python program.
- Understand the `print()` function.
- Learn how to write comments.
- Practise writing code independently.

## 📚 Learning Resource

[GeeksforGeeks - Introduction to Python](https://www.geeksforgeeks.org/python/introduction-to-python/)

## 📂 Files in This Folder

| File | Description |
|---|---|
| `01-introduction-to-python.py` | Introduction to Python |
| `02-hello-world.py` | First Python program |
| `03-comments.py` | Comments in Python |

## 🛠️ Requirements

- Python 3
- Visual Studio Code or another code editor
- Basic computer knowledge

## ▶️ How to Run the Programs

Open the terminal in the repository's root folder and run:

```bash
python 00-getting-started/01-introduction-to-python.py
```

## 💡 My Learning Method

Read → Understand → Type → Run → Experiment → Practise → Review

My goal is to understand every program I write instead of blindly copying code from tutorials.
