## ▶️ How to Run a Python Program

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal using **Terminal → New Terminal**.
4. Run the following command from the repository's root directory:

```bash
python 00-getting-started/01-hello-world.py
```

If your system uses the Windows Python launcher, you can use `py` instead of `python`.

## 💡 Concepts Learned

### 1. The `print()` Function

The `print()` function displays output on the screen.

```python
print("Hello World")
print ("My Name is Akshay Khapare")
print ("This is My Python Journey")
```

### 2. Variables

Variables store values that can be used later in a program.

```python
name = "Akshay Khapare"
age = 20
marks = 95.55
is_student = True
```
