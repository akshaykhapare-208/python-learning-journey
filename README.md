## 📖 My Learning Method

I follow this process for every topic:

1. **Read** — Study the concept on GeeksforGeeks.
2. **Understand** — Learn what the code does and why it works.
3. **Write** — Type the code myself.
4. **Run** — Execute the program and observe the output.
5. **Experiment** — Change the code and test different inputs.
6. **Practise** — Solve similar problems without looking at the solution.
7. **Debug** — Understand and fix errors.
8. **Review** — Revisit previous concepts.
9. **Commit** — Save meaningful progress to GitHub.

My goal is not just to complete tutorials, but to become capable of solving problems independently.
