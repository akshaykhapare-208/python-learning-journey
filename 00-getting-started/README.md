# 00 - Getting Started with Python 🐍

## 🎯 Objective
Learn how to set up Python, write my first program, and run Python scripts.

## 📚 Topics Covered
- What is Python?
- Installing Python
- Setting up a code editor
- Writing and running a Python program
- Understanding `print()`
- Introduction to variables
- Taking input from users
